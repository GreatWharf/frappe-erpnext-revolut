# Using Revolut Bank Feed

Built by Great Wharf for our internal ERPNext use and shared publicly. Unofficial; not affiliated with Revolut or Frappe.

## Start here

- **Revolut Business Grow or above** is required for Business API access. Basic and personal accounts are not supported. [Revolut requirements](https://help.revolut.com/business/help/integrating-with-external-apps/revolut-business-api/question-using-revolut-business-api/).
- Use **ERPNext v16** with the app installed and a **System Manager** login for setup.
- Open **Home → Revolut Bank Feed** or **Accounting → Banking → Connect Revolut**.
