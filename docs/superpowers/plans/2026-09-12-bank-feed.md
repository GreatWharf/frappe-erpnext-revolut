# Revolut Bank Feed Implementation Plan

**Goal:** Deliver a read-only, auditable bank feed for ERPNext v15.
**Architecture:** Pure data/client logic isolated from Frappe persistence; transaction ledger and unique leg keys make replay safe; all work shares a connection lock.
**Tech Stack:** Python, Frappe v15, ERPNext v15, MariaDB, Redis/RQ, requests, PyJWT.
**Spec:** ../../design.md

## Global constraints

READ scope only. No payment/write API routes. No GL posting. Encrypted secret fields. Explicit Company and currency validation. Durable replay and review for financial changes. Source facts verified against official docs on 2026-09-12.
